# back_go_general

This project is part of the Arcadion Ecosystem and strictly follows **Spec-Driven Development (SDD)** and Clean / Hexagonal Architecture.

## Documentation & Rules
The complete set of governing rules, technical baselines, and workflows are located in the .ai/rules/ directory.

- **.ai/rules/constitution.md**: The supreme governing ruleset for this project. Start here.
- **.ai/rules/architecture/**: Folder structure, Clean Architecture, and Hexagonal boundaries.
- **.ai/rules/standards/**: Code style, security rules, and specific patterns.
- **.ai/rules/workflows/**: Step-by-step guides for feature development, bug fixing, testing, and releases.

### AI Agents
If you are an AI (Claude, Gemini, etc.), refer to CLAUDE.md or GEMINI.md for initialization instructions.
You must read and follow the .ai/rules/ specifications before beginning any task.

## Specs Directory
The .ai/specs/ directory is used for Spec-Driven Development (SDD) tracking:
- **requirements/**: System requirements and business goals.
- **features/**: Detailed specifications for individual features.
- **tasks/**: Current tasks and agent todo lists.
- **workflows/**: Operational workflows.
- **decisions/**: Architecture Decision Records (ADRs).
- **integrations/**: 3rd party API integrations.
- **releases/**: Release notes and deployment plans.
